## Featured Projects

### ShrinkX — Distributed URL Shortener & Analytics Platform

Production-oriented URL shortening platform designed to practice distributed systems, caching, asynchronous processing, and system design.

- Built a URL shortening service using **Node.js, Express.js, PostgreSQL, Redis, and Kafka**
- Implemented **Redis cache-aside caching** for short-code lookups and URL generation
- Built an asynchronous **Kafka analytics pipeline** with a dedicated consumer for click tracking
- Implemented **Redis-backed fixed-window rate limiting** with fail-open behavior
- Generated compact short codes using **Base62 encoding** from PostgreSQL sequential IDs
- Containerized the multi-service architecture using **Docker Compose**
- Load tested with **k6 at 200 concurrent virtual users**, achieving approximately **3,120 RPS on redirects** and **2,574 RPS on URL generation with 0% errors**
- Tested failure scenarios involving Redis, Kafka, PostgreSQL, and backend restarts

**Tech:** Node.js, Express.js, PostgreSQL, Redis, Apache Kafka, Docker, k6

Full-stack MERN e-commerce platform with authentication, role-based access control, payment processing, and performance optimizations.
